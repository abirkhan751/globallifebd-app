# GLOBAL LIFE BD - Android App (Official)

This is the complete Android WebView Application source code for **Global Life BD** (https://globallifebd.com).

## 🚀 Key Features
- **Modern WebView Engine:** Hardware accelerated, fast loading, responsive layout.
- **File & Camera Uploads:** Fully supports taking photos with the camera or choosing files from gallery (essential for payment slip and KYC uploads).
- **Pull to Refresh:** Swipe down to reload pages easily.
- **Smart Back Navigation:** Back button history navigation with double-tap to exit.
- **Direct App Openers:** External URLs (WhatsApp, Telegram, Phone dialer, Email) open in their respective native apps directly.
- **Offline Screen:** Shows clean offline alert with "পুনরায় চেষ্টা করুন" (Retry) button when internet connection is lost.
- **Download Support:** Download receipts and PDFs directly with Android DownloadManager.
- **GitHub Actions Auto-Build:** Builds `.apk` automatically in 2 minutes on GitHub!

---

## 📲 How to Build and Download APK via GitHub:
1. Open this `globallifebd-android-app` folder in VS Code.
2. Initialize Git and push to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Global Life BD Android App"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. Go to your GitHub repository in your browser and click the **Actions** tab.
4. GitHub Actions will automatically start building the APK.
5. In ~2 minutes, when the green checkmark appears, click the completed build and download **GlobalLifeBD-Android-App-APK**!
6. Copy to your phone and install!
